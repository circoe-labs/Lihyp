QUALITÉ DU MODÈLE

Ce qui est réellement pris en charge

Calcul de consommation distance + temps, TCO variable / véhicule / exploitation, émissions directes ou puits-roue, affectation sans réemploi de véhicules.

Le moteur ne réalise pas encore l'optimisation réseau, la recharge, les dépôts multi-jours, la réglementation ou l'ACV complète.
