API de routage

Choisissez le fournisseur de calcul des trajets. Les clés sont conservées côté serveur, jamais dans la simulation.

Calcul d'itinéraire bus et camion

Geoapify propose les profils bus, camion 22 t et poids lourd 40 t. Ces profils ne certifient pas toutes les restrictions locales.

Fournisseur— Profil— Endpoint— Clé Geoapify— Clé ORS—

Le profil bus est préférable pour les autocars, mais les dimensions, la réglementation et l'accès réel restent à vérifier.

Geoapify — bus / camion

Profil bus par défaut ; camion standard 22 t et lourd 40 t disponibles.

Obtenir une clé Geoapify

openrouteservice (ORS)

Routage de secours configurable. Profil camion disponible, limitations à vérifier.

Obtenir une clé ORS

La configuration des clés est réservée à l'exploitant connecté sur le serveur local. Pour une application hébergée, utiliser des variables d'environnement ou un coffre-fort de secrets.
